# Сервис ведения списка сотрудников кластера
## Что позволяет выполнить приложение
- Получить список с информацией о всех сотрудниках кластера
- Получить сведения об одном сотруднике по его id
- Удалить сотрудника из списка по его id
- Удалить несколько сотрудников из списка по их id
- Обновить сведения о сотруднике

## Каким образом реализован сервис?
Сервис реализован в виде веб-сервиса предоставляющего API в форме RESTful API.

### API
| **№** | **Метод**  | **Эндпоинт**                    | **Описание**                                         |
|:-----:|:----------:|:--------------------------------|:-----------------------------------------------------|
|   1   |  **GET**   | `/api/v1/employees`             | Получает список сотрудников.                         |
|   2   |  **GET**   | `/api/v1/employees/{id}`        | Получает инфо по определенному сотруднику по его ID. |
|   3   |  **POST**  | `/api/v1/employees`             | Создание записи о новом сотруднике.                  |
|   4   |  **PUT**   | `/api/v1/employees/{id}`        | Обновляет запись о существующем сотруднике.          |
|   5   | **DELETE** | `/api/v1/employees/{id}`        | Удаляет сотрудника по ID.                            |
|   6   | **DELETE** | `/api/v1/employees/delete-list` | Удаляет сотрудников по списку ID.                    |

## Как запустить проект?
### При помощи IDE IntellijIDEA 
В классе Main в IDE GigaIDE выбрать иконку старт

### При помощи maven
Через maven ``` ./mvnw spring-boot:run ```

## Как протестировать запросы?
- Запустить проект средствами IDE или maven. Запустится на порте 9091
- В папке test-api в файле endpoints.http выбрать нужный эндпоинт и нажать кнопку запуска
- В терминале будут результаты работы утилиты
